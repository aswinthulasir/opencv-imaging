# OpenCV Imaging

This repository contains various Jupyter Notebooks demonstrating image alteration and segmentation techniques using OpenCV in Python.

## Contents

- **Affine and Perspective Transformation**: Learn how to perform affine and perspective transformations on images.
- **Drawing Lines and Shapes**: Explore how to draw geometric shapes and lines on images.
- **Exploring Color Models**: Understand different color models and their applications.
- **Text on Images**: Add and customize text on images.

## Requirements

- Python 3.7+
- OpenCV
- NumPy
- Matplotlib

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/aswinthulasir/opencv-imaging.git
   ```

2. Navigate to the repository directory:
   ```bash
   cd opencv-imaging
   ```

3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Open the Jupyter Notebooks to explore the examples:
   ```bash
   jupyter notebook
   ```
