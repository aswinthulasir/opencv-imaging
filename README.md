# OpenCV Imaging

## Description

This repository contains various Jupyter Notebooks demonstrating image alteration and segmentation techniques using OpenCV and Python. The notebooks cover topics such as affine transformations, perspective transformations, and more.

## Notebooks

- **Affine and Perspective Transformation**: Learn how to apply affine and perspective transformations to images.
- **Exploring Color Models**: Understand different color models and their applications.
- **Drawing Lines and Shapes**: Create and manipulate shapes and lines on images.
- **Text on Images**: Add and customize text on images.

## Requirements

- Python 3.x
- OpenCV
- NumPy
- Matplotlib

## Usage

Clone the repository and explore the notebooks to learn and experiment with image processing techniques.

```bash
# Clone the repository
git clone https://github.com/aswinthulasir/opencv-imaging.git

# Navigate to the repository
cd opencv-imaging

# Install dependencies
pip install -r requirements.txt
```
